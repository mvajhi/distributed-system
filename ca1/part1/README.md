**۱. ترتیب و نحوه اجرای برنامه‌ها**
برای اجرای صحیح، ابتدا باید پردازش Worker اجرا شود تا لوله‌های ارتباطی (Named Pipes) ایجاد شوند و برنامه در حالت گوش دادن قرار گیرد. سپس پردازش Interface در یک ترمینال مجزا اجرا می‌شود.

مرحله اول - اجرای Worker در ترمینال اول:
```bash
go run worker.go
```

مرحله دوم - اجرای Interface در ترمینال دوم:
```bash
go run interface.go
```

**۲. نمونه ورودی و خروجی**
پس از اجرای Interface، می‌توان دستورات را وارد کرد. در اینجا چند نمونه از اجرای موفق و مدیریت خطا آورده شده است:

```text
> ADD 5 7
OK 12

> SUB 10 3
OK 7

> DIV 8 0
ERR division_by_zero

> MOD 10 3
OK 1

> POW 2 3
OK 8

> ADD 5
ERR invalid_argument_count
```

**۳. پروتکل تبادل پیام**
ارتباط بین این دو پردازش کاملاً مستقل، از طریق دو Named Pipe مجزا (یکی برای ارسال درخواست و دیگری برای دریافت پاسخ) صورت می‌گیرد. قالب تبادل داده‌ها استاندارد JSON است. 
پردازش Interface ابتدا فرمت ورودی کاربر را بررسی کرده و در صورت صحت، آن را به یک آبجکت JSON تبدیل و روی لوله می‌نویسد. پردازش Worker این پیام را استخراج (Unmarshal) کرده، عملیات ریاضی را انجام می‌دهد و نتیجه را در قالب یک پاسخ JSON که شامل وضعیت (Status) و مقدار خروجی (Result) یا پیام خطا (Message) است، روی لوله پاسخ برمی‌گرداند. استفاده از قالب JSON امکان توسعه آسان‌تر و مدیریت یکپارچه خطاها را فراهم کرده است.
