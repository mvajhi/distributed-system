### ۱. دستور ساخت Docker Image
برای ساخت ایماژهای تعریف شده در فایل کامپوز، از دستور زیر استفاده می‌شود:

```bash
docker compose build
```

### ۲. دستور اجرای کانتینر
برای راه‌اندازی سرویس‌ها و اجرای کانتینرها در پس‌زمینه (Detach mode) از طریق داکر کامپوز:

```bash
docker compose up -d
```

*نکته: در صورتی که نیاز به بیلد و اجرای هم‌زمان باشد:*
```bash
docker compose up -d --build
```

### ۳. شماره پورت استفاده شده
طبق تنظیمات سرویس `calc-service`:
* **Host Port (VM):** `8080`
* **Container Port:** `8080`

### ۴. روش اتصال از Host به VM
اتصال از سیستم میزبان به ماشین مجازی از طریق **Private Network** با آی‌پی استاتیک تعریف شده در `Vagrantfile` برقرار می‌شود. تمامی درخواست‌ها از سیستم اصلی به این آدرس هدایت می‌شوند:

* **Static IP:** `192.168.56.10`

### ۵. نمونه دستور curl و فراخوانی از مرورگر
برای تست سرویس از روی سیستم میزبان (خارج از VM)، از دستور زیر استفاده کنید:

**استفاده از cURL:**
```bash
curl http://192.168.56.10:8080
```

**استفاده از مرورگر:**
آدرس زیر را در نوار آدرس مرورگر خود وارد کنید:
```text
http://192.168.56.10:8080
```
